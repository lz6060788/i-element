# Options 选项容器

对`options`进行了一层封装处理，支持多选、单选等，便于下拉列表在不同场景中的应用，如选择器、输入提示等。

## 基础用法

支持通过属性`options`来配置选项，也支持通过`slot`渲染选项

:::
